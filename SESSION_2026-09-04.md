## ✅ Built and verified this session

1. **Jumu'ah location is now automatic.** Marking Friday's Dhuhr "Done" always
   sets location = mosque; "Kaza" always sets location = home (an ordinary,
   alone Dhuhr — Jumu'ah has no kaza). Enforced server-side in
   `salat.service.ts`. Verified live against your account before committing.

2. **Kaza debt is now fully automatic.** Any prayer whose day passes while
   still unmarked is swept into "missed" + the debt counter automatically
   (`ensureCaughtUp` in `salatDebt.service.ts`), no manual Miss tap needed.
   A new debt record starts counting from _today_, never retroactively.

3. **"Reset kaza debt" button** — zeroes the counters and restarts the
   counting period from today, without touching your prayer history.
   `POST /api/salat/debt/reset`.

4. **Debt edit control simplified**, per your feedback mid-session: the
   per-prayer −/number/+ stepper is gone, replaced with a single plain
   number field per prayer that saves on blur or Enter. One way to correct
   a count, not three.

5. **Apple sign-in removed** — required a paid ($99/yr) Apple Developer
   account just to configure; wasn't worth it. Google sign-in unaffected.

6. **Local dev environment fixed** — stray backend process on port 5000
   killed, frontend dev port moved to 5173 to match the backend's
   `FRONTEND_ORIGIN` CORS allowlist (was silently failing every API call).
